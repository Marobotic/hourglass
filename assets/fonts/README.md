# Note fonts

The fonts a note can use, Regular and Bold, all under the SIL Open Font
License 1.1 (https://openfontlicense.org): Inter (the default), Lora,
JetBrains Mono, Caveat and Playfair Display, from Google Fonts.

Every app carries copies: `windows|linux/app/Hourglass/fonts/`,
`android/app/src/main/res/font/` (lower-case names) and
`ios/Hourglass/Resources/Fonts/`. The list itself is `FONTS` in
`core/noteformat.js`.
