Dynamic programming

AlgorithmsTue 6 OctEdited 2 min ago 4 versions

Two ideas make a problem a DP problem: overlapping subproblems and optimal substructure. If both hold, solve each subproblem once and reuse the answer.

Memoisation vs tabulation

  • Top-down: recursion plus a cache. Easy to write, only solves what it needs.
  • Bottom-up: fill a table in order. No recursion depth, easy to save memory.

0/1 knapsack

Rows are items, columns are capacity. Each cell takes the better of skipping the item or taking it and looking up the remaining capacity.

best[i][w] = max(best[i-1][w], v[i] + best[i-1][w - wt[i]])
